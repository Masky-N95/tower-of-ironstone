# The Tower of Ironstone

A co-op PS1-style tower crawl.

**Download the launcher:**
- Windows: [IronstoneLauncher-win64.zip](https://github.com/Masky-N95/tower-of-ironstone/releases/latest/download/IronstoneLauncher-win64.zip). Unzip, run IronstoneLauncher.exe.
- macOS: [IronstoneLauncher-mac.zip](https://github.com/Masky-N95/tower-of-ironstone/releases/latest/download/IronstoneLauncher-mac.zip). Unzip, double-click Start Ironstone.command (first time: right-click > Open).

Press PLAY. The launcher keeps the game up to date. This repo holds builds only.
