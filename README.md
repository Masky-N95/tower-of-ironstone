# The Tower of Ironstone

A co-op PS1-style tower crawl.

**Download:** [IronstoneLauncher-win64.zip](https://github.com/Masky-N95/tower-of-ironstone/releases/latest/download/IronstoneLauncher-win64.zip) (Windows). Unzip, run IronstoneLauncher.exe, press PLAY. The launcher keeps the game up to date.

This repo holds builds only.
